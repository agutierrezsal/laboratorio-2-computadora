# Dentro de la computadora

**Laboratorio 2 · Arquitectura de Computadoras**  
**Autor:** Manuel Alejandro Gutiérrez Salazar

Página web interactiva para conocer las partes de una computadora, comprender cómo colaboran entre sí y explorar modelos comerciales de referencia. El proyecto está desarrollado en un solo archivo `index.html`, con el CSS y el JavaScript integrados.

## Contenido e interactividad

- **Explorador del gabinete:** permite seleccionar piezas del esquema y leer su función, un ejemplo de modelo actual, una característica relevante y una consideración de compatibilidad.
- **Componentes internos:** gabinete, placa base, CPU, RAM, refrigeración, GPU, SSD, fuente de alimentación y puertos/red.
- **Periféricos:** monitor, teclado y ratón.
- **Recorridos de datos:** explican qué ocurre al abrir un programa, jugar y guardar un archivo.
- **Mini reto:** cinco preguntas con respuesta inmediata y puntuación final.
- **Referencias:** enlaces a las fichas técnicas oficiales de los modelos mencionados.

Los modelos se presentan con fines educativos. Sirven para identificar tecnologías actuales y practicar la lectura de especificaciones; no forman una lista obligatoria de compra.

## Cómo usarlo

1. Abre `index.html` en un navegador o visita el enlace de GitHub Pages.
2. Haz clic en los puntos del gabinete o en las etiquetas de los periféricos para explorar cada componente.
3. Selecciona una de las tres acciones en **«¿Qué pasa cuando…?»** y avanza por sus etapas.
4. Responde el cuestionario de la sección **«Mini reto»**.

La interfaz y las actividades funcionan sin instalar dependencias. Los enlaces a las fichas de los fabricantes sí requieren conexión a internet.
